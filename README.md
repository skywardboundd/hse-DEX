# DEX Backend

Бэкенд для децентрализованной биржи (DEX), разработанный для обработки и индексации данных блокчейна, обеспечения торговых операций и предоставления API для взаимодействия с фронтендом.

## Структура проекта

Проект состоит из следующих основных компонентов:


- Индексер
- Core 
- Бот
- API

## Начало работы

1. Убедитесь, что у вас установлены все необходимые зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения в файле `.env`:
   ```
   TONCONNECTOR_TOKEN=
   TONAPI_KEY=
   TOKEN=
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=dex_db
   DB_USER=sdf
   DB_PASSWORD=postgres
   ```

3. Запустите компоненты системы:
   ```
   # Запуск API
   python api/run.py
   
   # Запуск бота (опционально)
   python src/main.py
   ```

## Архитектура

Компоненты системы взаимодействуют между собой через базу данных и очереди сообщений:

1. **Индексер** получает данные из блокчейна и сохраняет их в базу данных
2. **Core** использует эти данные для выполнения бизнес-логики DEX
3. **API** предоставляет интерфейс для взаимодействия с системой
4. **Бот** анализирует данные и выполняет автоматические операции
